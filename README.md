# github-core-clone-01

A from-scratch reimplementation of GitHub's core API surface — repositories, issues, pull requests, plus GraphQL and MCP endpoints — as a TypeScript/Node service, built for a clone-conformance competition. `app.ts` holds the bulk of the route handlers; `git.ts`, `graphql.ts` and `mcp.ts` cover the git, GraphQL and MCP surfaces.

Status: Local conformance 120/120 + perf 172/200; stage checked; deadline 2026-11-21.
